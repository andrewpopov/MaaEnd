- Main Field: Ultimate > Combo Skill > Basic Attack > Battle Skill

Choose the loadout for its intended team and resource thresholds. An investment priority is not a button sequence. Refer to the original guide for stat targets, calculations, substitutions, and combat details.
Arcane has attribute-selected forms. INT uses Intellect >= Will; WILL uses Will > Intellect. Equipment changes can switch forms, so DPS and support loadouts must be matched to the intended team.
